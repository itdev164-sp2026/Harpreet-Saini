## Live Site
🔗 **Deployed at:** [https://harpreet-saini.vercel.app](https://harpreet-saini.vercel.app)

## Project Overview
Full-stack project management application with authentication, database integration, and automated testing.

## Features
- 🔐 Authentication (Sign up / Sign in)
- 📊 Project Management (Create, view projects)
- 🎨 Dark Mode Toggle
- 📱 Responsive Design
- 🧪 E2E Testing with Playwright
- 🚀 CI/CD Pipeline with Vercel

## Tech Stack
- Next.js 15
- TypeScript
- Supabase (Auth + Database)
- Tailwind CSS
- Playwright
- Vercel

## Local Development

\`\`\`bash
npm install
npm run dev
